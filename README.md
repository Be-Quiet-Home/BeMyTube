# BeMyTube

BeMyTube is an experimental Haiku-native video client shell.

The project explores how FreeTube's renderer, provider logic, and privacy-focused
ideas can be mapped into a native Haiku application without carrying Electron as
the application runtime.

FreeTube is kept as a vendored upstream reference under:

    vendor/Freetube-App/

BeMyTube is not maintained as a traditional FreeTube fork. Upstream changes are
imported deliberately as reviewed code deltas.
